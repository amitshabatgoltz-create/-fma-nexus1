# מפת חיבורים · כפפה אחת

כל החיבורים בלי הלחמה (ג'אמפרים, שרוולים ו-Wago), חוץ מ-4 הלחמות במודול הטעינה (2 לסוללה, 2ליציאת ה-5V).

## מהנאנו

ג'אמפר נקבה על הפין, והקצה השני חתוך.

| פין | לאן |
|---|---|
| D4 | כפתור ירוק (רגל 1) |
| D7 | כפתור כחול (רגל 1) |
| D2 | כפתור אדום (רגל 1) |
| D5 | SIG ב-IRF520 #1 (מנועים) |
| D9 | SIG ב-IRF520 #2 (לוגו) |
| D6 | SIG ב-IRF520 #3 (מחמם) |
| A0 | שרוול כחול A (חיישן) |
| 5V | Wago 5V |
| GND | Wago GND קטן |

## כפתורים

רגל 2 של שלושת הכפתורים מתחברת יחד בשרוולים כחולים לחוט אחד, שהולך ל-Wago GND קטן.

## שרוול כחול A (חיישן החום)

3 חוטים בשרוול אחד: הג'אמפר מ-A0, גיד ה-NTC מהכבל, ורגל אחת של נגד 10K. הרגל השנייה של הנגד הולכת ל-Wago GND קטן.

## IRF520 (3 מודולים)

| חיבור | לאן |
|---|---|
| SIG | מהנאנו: #1 מ-D5, #2 מ-D9, #3 מ-D6 |
| בורג V− | גיד בכבל: #1 מנועים−, #2 לוגו−, #3 מחמם− |
| בורג GND | Wago GND גדול |
| VCC, V+, VIN | לא מחוברים |

## יחידת החשמל

- חור +5V במודול ← מתג ← Wago 5V
- חור −5V במודול ← Wago GND גדול

## דיודה (1N5819)

הצד עם הפס ← Wago 5V. הצד השני ← בורג V− של IRF520 #1, יחד עם גיד המנועים. פס הפוך = קצר כשהמנועים נדלקים.

## 3 ה-Wago

| Wago | מה נכנס |
|---|---|
| 5V | מתג, נאנו 5V, גיד 5V של הכבל, הפס של הדיודה |
| GND גדול | מודול −5V, 3 ברגי GND של ה-IRF520, חוט גשר ל-GND הקטן |
| GND קטן | נאנו GND, הכפתורים, הנגד 10K, חוט הגשר |

## הכבל (5 גידים) ובצד הכפפה

| גיד | בכפפה מתחבר ל |
|---|---|
| 5V | + של 5 המנועים, + של הלוגו, חוט אחד של המחמם, רגל אחת של ה-NTC (פיצול בשרוולים כחולים) |
| מנועים− | − של 5 המנועים (שרוולים כחולים) |
| לוגו− | − של מחבר הפס (שרוול לבן) |
| מחמם− | החוט השני של המחמם (שרוול לבן) |
| NTC | הרגל השנייה של ה-NTC (שרוול לבן) |

לפני שמתחילים: לקבוע איזה צבע בכבל הוא איזה גיד, לכתוב, ולשמור על אותו סדר בכל הכפפות.
