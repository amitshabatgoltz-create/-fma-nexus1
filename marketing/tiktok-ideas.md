## "אבא, כמה לייקים אתה קונה לי את זה?" (צ'אט וואטסאפ, 2 משתתפים)

יוצרים את הצ'אט באפליקציית Fake Chat או ב-Canva.

| מי | הודעה |
|---|---|
| אני | אבא, כמה לייקים אתה קונה לי את זה? |
| אני | 📸 תמונה של הכפפה |
| אבא | מה זה בכלל? 😂 |
| אני | כפפת מסאז' וחימום לנגנים וגיימרים. בדיוק כמוני |
| אבא | טוב, כמה זה עולה? |
| אני | יש עכשיו מבצע מטורף! הדרופ הראשון ב-₪180 בלבד (במקום ₪249) |
| אני | ומשלוח חינם ל-3 הלקוחות הראשונים. אחד כבר נתפס 😱 |
| אבא | 500 לייקים ואני קונה |
| אני | בסדר, שימו לייייייק 🙏 |

כיתוב:
> עזרו לי לשכנע את אבא 🙏 500 לייקים!
> #גיטרה #גיימינג #fmatech

לפני העלאה:
- לוודא שהמחיר בסרטון זהה למחיר באתר (179 או 180).
- להפעיל בהגדרות ההעלאה: גילוי תוכן ← "המותג שלך".
- אם מגיעים ל-500 לייקים: סרטון המשך "הגענו! אבא, תשלם 😂".

## "מטרות 2026" (לסוף דצמבר)

צילום מלמעלה (חצובה) של דף עם צ'ק ליסט, טוש שחור עבה. כל מטרה נמחקת בקו אחד ומעליה נכתב התיקון:

1. להרוויח 50,000 ₪ ← מוחקים "000" ← 50 ₪
2. להגיע ל-10,000 עוקבים ← מוחקים "00" ← 100
3. לקום מוקדם כל יום ← מוחקים "מוקדם" ← בצהריים
4. לקנות אייפון מתקפל ← מוחקים ← כיסוי לאייפון
5. לפתח כפפת מסאז' לנגנים וגיימרים ← ✅ וי גדול, ואז הכפפה נכנסת לפריים דולקת, באור כבוי

כיתוב:
> 2026: לא הכל הלך כמו שתכננתי... אבל דבר אחד כן 🧤✨
> #סוףשנה #מטרות #מותגצעיר #גיטרה #fmatech

תנאי: הכפפה (לפחות אב טיפוס שעובד ונראה טוב) מוכנה עד סוף דצמבר.
