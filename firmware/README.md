# Nexus-1 — קושחת ארדואינו

הקובץ `nexus1/nexus1.ino` נטען ל-Arduino Nano דרך Arduino IDE (Board: Arduino Nano, Processor: ATmega328P).

## חיווט

| רכיב | פין | הערה |
|---|---|---|
| כפתור אדום — חימום | D2 | בין הפין ל-GND (נגד pull-up פנימי) |
| כפתור ירוק — עיסוי | D4 | בין הפין ל-GND |
| כפתור כחול — אורות | D7 | בין הפין ל-GND |
| פסי לד COB צהובים (כל האצבעות) | D9 (PWM) | דרך MOSFET לוגי (למשל AO3400 / IRLZ44N) |
| מנועי רטט | D5 (PWM) | דרך MOSFET + דיודת flyback על כל מנוע |
| אלמנט חימום 5V | D6 (PWM) | דרך MOSFET |
| טרמיסטור NTC 10k (אופציונלי) | A0 | מחלק מתח עם נגד 10k ל-5V, צמוד לגוף החימום |

כל ה-GND משותפים: סוללה, ארדואינו, MOSFETים וכל העומסים.

## שימוש

- **אדום:** כבוי ← חמים ← חם ← כבוי. החימום נכבה לבד אחרי 20 דקות.
- **ירוק:** כבוי ← חלש ← בינוני ← חזק ← פולסים ← כבוי.
- **כחול:** כבוי ← קבוע ← הבהוב ← נשימה ← כבוי.
- **לחיצה ארוכה (2 שניות) על כל כפתור:** הכל כבוי.

## הערות חשובות

- **אסור לחבר לד, מנוע או חימום ישירות לפין** — פין של נאנו נותן כ-20mA בלבד. כל עומס עובר דרך MOSFET.
- **חיבור פסי הלד באצבע:** מחבר ה-JST / הקליפס ממשיך את הפס (+ ל-+, − ל-−), כלומר חשמלית שני הקטעים במקביל. אם תחברו אותם בטור אמיתי על 5V הם יאירו חלש מאוד או לא יאירו.
- **חימום על העור:** בלי טרמיסטור החימום עובד בעוצמה קבועה ומוגבלת. כדי לשמור על טמפרטורה יציבה באמת, הוסיפו טרמיסטור ושנו בקוד `USE_THERMISTOR` ל-`1` (יעד 38°C / 41°C, ניתוק מעל 43°C).
- **סוללה:** מנועים + חימום + לדים יכולים למשוך יותר מ-1A יחד. בחרו סוללה / פאוורבנק 5V שמספקת לפחות 2A.
