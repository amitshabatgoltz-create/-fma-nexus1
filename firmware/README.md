# קושחת הכפפה · FMA Nexus-1

**הקוד העדכני: `fma_glove/fma_glove.ino`.** מעלים אותו ל-Arduino Nano דרך Arduino IDE (Board: Arduino Nano, Processor: ATmega328P, ואם ההעלאה נכשלת: ATmega328P (Old Bootloader)).

- `massage_programs/` · קוד המנועים בלבד, הבסיס של הקוד המלא.
- `nexus1/` · גרסה ישנה. לא להשתמש בה.

## חיווט

| רכיב | פין | הערה |
|---|---|---|
| כפתור ירוק | D4 | בין הפין ל-GND, בלי נגד |
| כפתור כחול | D7 | בין הפין ל-GND |
| כפתור אדום | D2 | בין הפין ל-GND |
| מנועי רטט | D5 | דרך מודול IRF520 |
| לוגו (פסי LED) | D9 | דרך מודול IRF520 |
| מחמם | D6 | דרך מודול IRF520 |
| חיישן חום NTC 10K | A0 | 5V ── נגד 10K ── A0 ── NTC ── GND. ה-NTC צמוד לעור, ליד המחמם |

כל ה-GND משותפים. אף עומס (מנוע, לד, מחמם) לא מתחבר ישירות לפין.

## שימוש

- **לחיצה קצרה:** תוכנית עיסוי. ירוק 2 דקות, כחול 4, אדום 6. אותו כפתור שוב: עצירה. שוב תוך 20 שניות: ממשיך מאיפה שעצר.
- **לחיצה ארוכה (שנייה וחצי):** חימום. ירוק חלש (35°C), כחול בינוני (38°C), אדום חזק (40°C). לחיצה ארוכה על אותו צבע שוב: חימום כבוי.
- **הלוגו:** עוצמת האור מראה את רמת החימום: עמום = כבוי, ואז חלש, בינוני ומלא. בלי הבהובים.
- **שינה:** אחרי 20 שניות בלי תוכנית ובלי חימום. לחיצה על כל כפתור מעירה.

## בטיחות

- החימום לא עובר 40°C על העור.
- אם החיישן מנותק או בקצר, החימום נכבה ולא נדלק.
- החימום נכבה לבד אחרי 30 דקות.

## בדיקה ב-Wokwi, לפני שהחלקים מגיעים

1. ב-wokwi.com פותחים פרויקט חדש של Arduino Nano.
2. בלשונית `sketch.ino` מדביקים את כל `fma_glove.ino`.
3. בלשונית `diagram.json` מדביקים את כל `fma_glove/diagram.json`. כל החלקים והחוטים מופיעים לבד.
4. מריצים. נורית צהובה = מנוע, אדומה = מחמם, לבנה = לוגו.
5. הכפתורים עובדים גם במקלדת: 1 ירוק, 2 כחול, 3 אדום. לחיצה ארוכה = מחזיקים את המקש.
6. לוחצים על חיישן החום ומזיזים את הסליידר כדי לשנות טמפרטורה. ב-Serial Monitor רואים את הטמפרטורה ואת מצב המחמם כל שנייה.

במוצר הסופי אפשר לשנות בקוד `#define DEBUG 1` ל-`0`.
